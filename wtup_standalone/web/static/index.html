WTUP OpenAPI 接口文档

面向第三方机器人 (如 AstrBot)、自动化脚本与外部看板的标准化 RESTful API。支持通过 target=mobile 无缝获取手游拆包数据。
通用规范 端游与手游参数区分说明
所有查询与操作 API 缺省针对端游 (PC / Console)。如需查询或操作手游 (War Thunder Mobile)，仅需在请求中追加查询参数 ?target=mobile 或在 POST JSON Body 中附带 "target": "mobile"。
方法 路径 (Path) 关键参数 说明
GET /api/status ?target=mobile 查询系统运行状态、任务状态、两端仓库地址与下一次轮询时间
GET /api/latest ?target=mobile 获取最新一次成功分析的报告 JSON，包含标题、重要度、图片地址等 (供 AstrBot 轮询)
GET /api/history ?target=mobile 获取历史报告列表摘要
GET /api/report-image/{id} ?template=discord 获取该报告渲染出的 PNG 图片文件流
GET /api/report-html/{id} ?watermark=1&wm_text=... 获取在线 HTML 完整报告网页
POST /api/analyze/trigger {"target":"mobile","mode":"latest"} 触发一次异步更新检查或版本比对分析
POST /api/reports/{id}/rerender {"render_scale":"2x"} 根据最新的分辨率清晰度与水印配置，秒级无损重新生成已有报告的图片
POST /api/git/sync {"target":"mobile"} 强制从 GitHub 增量 fetch 目标本地 Git 仓库
